Prototypes as solution

Date: 2026-11-03. The prototypes apply the design system to real screens. They use only design-system/mobve-design-system.css; data is illustrative. The Mobve name appears as text only: the logo was not redrawn, as the brand rules forbid replacing it.

1. Prototypes

FileWhat it shows
design-system/prototype.htmlWebsite: header, hero, scenario tabs, dark demo band, solutions, pricing, FAQ, contact form, footer. App: sidebar, header, information notice, KPI tiles, call volume chart, received and completed chart, attention panel, week of appointments, maintenance table, empty state, confirmation dialog
design-system/appointments.htmlAppointments screen with the structure of the current app: reporting filters, six scorecards, week calendar with category colors, attention panels, upcoming list with category and status
design-system/index.htmlDesign system reference with every component and state

3. How to view

Open the HTML files in a browser from this repository; they load the CSS by relative path and the Inter font from Google Fonts for the preview. PDF exports of each page are in docs/pdf/.
